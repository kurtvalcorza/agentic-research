# Academic Contribution Types Reference

Framework for identifying and framing different types of scholarly contributions.

---

## Primary Contribution Types

### 1. Empirical Contribution
**What:** New data, findings, or observations
**Language:** "This study provides evidence that..."

**Subtypes:**
- **Confirmatory:** Replicates prior findings in new context
- **Disconfirmatory:** Challenges established findings
- **Exploratory:** Discovers new patterns or relationships
- **Descriptive:** Documents previously undocumented phenomena

**Strength indicators:**
- Sample size and representativeness
- Effect size and significance
- Replicability potential

---

### 2. Theoretical Contribution
**What:** New concepts, frameworks, or explanatory models
**Language:** "This paper proposes a framework for..."

**Subtypes:**
- **Theory building:** Creates new explanatory framework
- **Theory extension:** Adds to existing theory
- **Theory refinement:** Improves precision of existing theory
- **Theory integration:** Synthesizes multiple theories

**Strength indicators:**
- Logical coherence
- Parsimony (simplicity)
- Explanatory power
- Testability

---

### 3. Methodological Contribution
**What:** New techniques, tools, or approaches for research
**Language:** "This paper introduces a method for..."

**Subtypes:**
- **New method:** Novel technique not previously used
- **Improved method:** Enhancement of existing approach
- **Comparative method:** Shows superiority of one approach
- **Validation method:** Tests reliability/validity of method

**Strength indicators:**
- Improvement over alternatives
- Generalizability
- Reproducibility
- Practical applicability

---

### 4. Practical/Applied Contribution
**What:** Solutions to real-world problems
**Language:** "This work addresses the challenge of..."

**Subtypes:**
- **Design:** Creates artifact, system, or intervention
- **Implementation:** Shows how to apply in practice
- **Evaluation:** Assesses practical effectiveness
- **Guidelines:** Provides actionable recommendations

**Strength indicators:**
- Problem significance
- Solution effectiveness
- Implementation feasibility
- Stakeholder impact

---

### 5. Synthesis/Review Contribution
**What:** Integration of existing knowledge
**Language:** "This review synthesizes evidence on..."

**Subtypes:**
- **Systematic review:** Comprehensive, reproducible synthesis
- **Meta-analysis:** Quantitative pooling of results
- **Narrative review:** Thematic integration
- **Scoping review:** Maps breadth of evidence

**Strength indicators:**
- Comprehensiveness
- Rigor of analysis
- Novel insights from synthesis
- Gap identification

## Contribution Positioning Matrix

| Your Work | Existing Literature | Positioning |
|-----------|---------------------|-------------|
| Supports | Consensus | "Confirming and extending..." |
| Supports | Minority view | "Providing additional evidence for..." |
| Challenges | Consensus | "Questioning the assumption that..." |
| Challenges | Minority view | "Refuting the claim that..." |
| Novel | Gap exists | "Addressing the unexplored question of..." |
| Novel | No gap obvious | "Revealing the overlooked importance of..." |

## Contribution Framing Templates

### Template 1: Gap-Filling
```
While prior research has established [Known],
little attention has been paid to [Gap].
This study addresses this gap by [Your contribution].
```

### Template 2: Challenge
```
Conventional wisdom holds that [Existing belief].
However, this paper demonstrates [Your counter-evidence],
suggesting that [New understanding].
```

### Template 3: Extension
```
Building on [Foundational work]'s framework,
this study extends the theory to [New context],
revealing [Novel insight].
```

### Template 4: Integration
```
Previous studies have examined [A] and [B] separately.
This paper synthesizes these perspectives,
showing [Integrated insight].
```

### Template 5: Practical
```
Despite theoretical understanding of [Topic],
practitioners lack guidance for [Practical problem].
This study provides [Actionable contribution].
```

## Overclaiming Warning Signs

| Overclaim | Appropriate Claim |
|-----------|-------------------|
| "First to study X" | "Among the first to study X in [context]" |
| "Proves that X" | "Provides evidence that X" |
| "Revolutionizes understanding" | "Contributes to understanding" |
| "Definitive answer" | "Important insight into" |
| "All contexts" | "In contexts similar to this study" |

## Contribution Strength Calibration

**Strong claims require:**
- Multiple converging evidence sources
- Large effect sizes
- High methodological rigor
- Replication or validation

**Moderate claims appropriate when:**
- Single study (even if rigorous)
- Moderate effect sizes
- Novel method (not yet validated)
- Specific context

**Weak claims necessary when:**
- Exploratory research
- Small samples
- Preliminary findings
- Narrow context

## Stakeholder-Specific Framing

### For Academics
- Emphasize theoretical implications
- Connect to disciplinary debates
- Highlight methodological rigor

### For Practitioners
- Emphasize practical applicability
- Provide implementation guidance
- Highlight immediate benefits

### For Policymakers
- Emphasize broader implications
- Connect to policy debates
- Highlight societal benefits

### For Funders
- Emphasize innovation
- Connect to strategic priorities
- Highlight potential impact
